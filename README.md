
# Python Job Listings Scraper

## Project Overview
A beginner-friendly Python web scraping project that extracts job listings from the Real Python Fake Jobs website.

## Features
- Extracts job titles
- Extracts company names
- Extracts job locations
- Extracts job detail URLs
- Saves results in a CSV file
- Handles missing information

## Technologies Used
- Python
- Requests
- BeautifulSoup
- CSV

## Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

## How to Run

Run the following command:

```bash
python job_scraper.py
```
## Output

The scraper generates a file named:

`job_listings.csv`

## Data Source
https://realpython.github.io/fake-jobs/
